# わから v2 練習帳 0.1.0

対応配列は2.0.0-beta.1。`index.html` をブラウザで開きます。フォルダ内のHTML・JS・CSSを一緒に置いてください。ネット接続やアカウントは不要です。macOS同梱版も同じ教材と画面です。

「キー位置の練習」は英字入力で指定キーを順に押します。システムの配列は変更しません。「日本語入力で練習」はWKR macOS等を使い、ひらがなの確定後にEnterで採点します。IME確定用のEnterと採点用のEnterを分けます。スペース変換後の漢字は見本のひらがなと一致しません。練習欄の外のキーや他アプリの入力は扱いません。

## 保存と削除

既定では保存オフ。明示的に有効化したときだけ、配列版、固定の課題ID、課題の完了回数、最高正答率（整数%）を保存します。日時・所要時間・キー列・誤入力文字列・行別の履歴は保存しません。途中の入力はメモリと練習欄だけに置きます。

- ブラウザ版: localStorageの `wakara.practice.v1.2.0.0-beta.1`。同じブラウザと配信元だけで使えます。file URLの保存の扱いはブラウザにより異なり、利用できない場合は保存せずに続けます。
- macOS同梱版: Public専用のApplication Support内 `practice-progress.json`（0600）。WebViewの永続キャッシュは使いません。利用者への説明はmacOS側の導入文書にも載せます。
- 「保存した成績をすべて削除」または保存チェックを外すと、この版の保存を消してオフにします。ブラウザのサイトデータ削除も利用できます。他の配列版の成績はその版のページで削除してください。

端末間の自動同期、エクスポート、Private版の練習ログの読込はありません。正答率はキー位置モードでは正しいキー / 押したキー、日本語入力モードでは正しい回答 / 提出した回答です。最高値は両モード共通なので研究評価の指標としては扱いません。

## 教材の変更

`lessons.json`に段階と読みを定義し、`../scripts/generate.py`でJSON規則からキー列を生成します。既存の移行練習で扱っていたん・っ、拗音、小書き、外来音は補助資料として参照し、公開版は基本キーから始める新しい構成です。入力原本や私的な練習ログは取り込みません。

`node --test practice/core.test.cjs` と `python3 -m unittest discover -s tests` をリポジトリルートで実行します。
