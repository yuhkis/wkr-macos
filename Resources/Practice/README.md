# わから v2 練習帳 0.5.1 — 公開候補

[公開済みのブラウザ版で体験する](https://yuhkis.github.io/wkr-layout/)（練習帳0.5.0 / 配列2.0.0-beta.5）。このソースは練習帳0.5.1候補で、公開Web・0.5.0の添付は更新していません。対応配列は2.0.0-beta.5（D＝た行、F＝な行、ん＝M、っ＝U、N＝いぇ、や＝P、記号・矢印の規則なし。キー配置は[配列表](../docs/layout-v2.md)）。Web版とこのソースから生成するオフラインZIPは同じ教材・変換処理を使います。macOS向けにも同じソースを取り込める構成です。現在公開済みのWKR macOS 0.8.0-public.beta.5に同梱する練習帳は0.1.0（配列2.0.0-beta.1）で、0.2.0以降を同梱するアプリは未公開です。Webは初回読み込みに通信し、ZIPとmacOS版はオフラインで動きます。PCの物理QWERTYキーボードが主対象です。

## 練習の切り替え

- **QWERTYで体験**: ABC・英数で入力。インストールやIME設定変更なしで、Hはあ、E→Kはきになります。WKR標準設定では英字入力は変換しないため、WKRを起動したまま使えます。Enterまたは「採点」ボタンで採点、Backspaceで仮表示全体を取り消すか確定した1文字を削除します。末尾編集だけを扱い、貼り付け・ドロップ・キーリピートは受け付けません。漢字変換はしません。記号位置はJIS基準、US記号キーとタッチキーボードは実機未確認です。
- **WKR・IMEで練習**: 普段のWKR v2とApple日本語入力のひらがなで入力。練習帳は再変換せず、IMEで確定した後のEnterまたは「採点」ボタンで採点します。入力途中や確定操作のEnterでは採点しません。確定キーの識別や離れの順序が曖昧な場合は、Enterによる採点を保留します。確定済みでEnterが反応しないときは「採点」を押してください。すべてのIMEで同じEnter回数になることは保証しません。Google日本語入力・azooKey用テーブルを使う方式もありますが、各IMEでの入力は未確認です。
- **自由に試す**: 同じモードで自由に入力。保存・採点はせず、消去ボタン、課題・モード切り替え、ページを閉じると消えます。

## 保存と削除

既定は保存オフ。有効にしたときだけ配列版・固定課題ID・完了回数・最高正答率（整数）を端末内に保存します。入力本文・誤入力・キー列・日時・所要時間は保存・送信しません。正答率は正しい回答 / 提出した回答で、両モード共通です。
Web/ブラウザの保存先はlocalStorageのwakara.practice.v2.2.0.0-beta.5（配列版ごとに分かれます。0.5.0と0.5.1は同じ配列版・集計形式なので、この配列版の課題別成績をそのまま読みます。以前の配列版の成績は wakara.practice.v2.2.0.0-beta.4 などの版ごとの名前に残り、引き継ぎません）。旧版のキー数による成績は自動移行しません。旧版の成績削除は旧版を開いて行います。macOSはアプリごとに独立したApplication Support内のpractice-progress-v2.jsonを使用します。Webとアプリ間の自動同期はありません。
「保存した成績をすべて削除」または保存チェックを外すと、この版の成績を消して保存を止めます。Webではブラウザのサイトデータ削除でも消せます。保存できないときも保存せずに練習できます。
解析タグは使用しません。公開Web版ではGitHubがアクセス元IPをセキュリティ目的で記録します。これは練習内容の記録ではありません。

## 教材と変換

教材はlessons.json、配列は../data/layout-v2.jsonが正本。python3 scripts/generate.pyでdata.jsを生成し、engine.jsが同じ171規則をページ内で解釈します。node --test practice/*.test.cjsとpython3 -m unittest discover -s testsで規則・教材・保存を検査します。

IME確定キーの識別状態はメモリ内だけで扱い、課題・モード切り替えやページ終了時に消します。キー履歴や細かな時刻を追加で保存しません。`app.test.cjs` は配布する `app.js` と変換・保存処理を合成DOMイベントで動かし、確定前後の順序、二重採点の防止、明示ボタン、集計だけの保存を検査します。実IMEでの検証とは区別します。
