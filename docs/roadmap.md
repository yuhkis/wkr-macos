# Public v2 の残件

検証済みの範囲は [verification.md](verification.md)、設計の根拠は [design.md](design.md) にまとめます。この文書は製品の残件を扱い、個人の環境や利用記録は載せません。

## 1. 公開前の整理

- macOS・配列・教材はいずれも確認済みソースから始まる独立履歴を使う。旧履歴・PR・Release・Actionsの保全とアクセス管理は公開候補と分ける。
- 新しい公開先の作成・最小基点の登録・PR・Releaseは、全ref・履歴・配布物の監査結果を揃え、最終承認後に行う。
- macOSは署名付きcommitのbranchとPRを使い、CI `swift-test`成功後にmerge commitで統合する。以前のリポジトリを公開先として再利用しない。
- ソースビルドとad-hoc署名・未公証zipを用意する。ダウンロード後の個別起動許可は、ローカルビルドやファイル転送からの起動と区別する。

## 2. メニュー・起動・停止

- 最初のPublic候補で権限付与と短い実変換、次の候補で練習の課題・配列図の表示を確認済み。版と確認範囲は検証記録を参照。
- 初回ベータの実機範囲は1台での短い確認。一時停止・終了後の通常入力は本人確認を残す。複数OS・新規ユーザー・長時間運用は未検証として扱う。
- 表示は形とテキストで区別する。VoiceOver、異なる画面構成、全対応OSでの可読性は未確認。
- 新しいPublic / Privateは共通の排他ロックを使う。未対応の旧版は先に終了する。Privateへの反映・改名・設定移行・実機配備はPrivate側で扱う。

## 3. 入力の互換性

- Apple日本語入力のひらがな、prefix方式、破棄可能なTextEdit文書を基本条件にする。短いかな、Space候補、Enter確定、Backspace、かな/英数、アプリ切替、停止復帰を別々に確認する。
- Notes・Safariなど対象アプリを増やすときは、既存の試験結果を流用せず、その版での結果を追記する。Google日本語入力・azooKeyの実IME試験も別項目とする。
- Unicode直接注入は未確定文字列中では抑止する。通常かなの互換性と同一視しない。未確定を確定させるためのReturnを自動送出しない。
- Controlショートカットと英字への打ち直しは、IMEのキー設定・アプリ・未確定の状態に依存する。設定違いを含めた実機確認は未完了。
- 仮想マシンではホストの入力ソースとゲストのIME状態が別に存在する。WKRによる自動切替や特定キーマップへの変更を前提にせず、別途試験条件を定める。

## 4. 練習と集計

- 初心者向けの12課題・127問をブラウザと同梱版で共有する。課題の表示確認と、実IMEでの採点・成績保存・削除は分けて評価する。
- 集計の回帰検証にはテストで生成した値と一般的なキーマップを使う。個人の集計ファイルや実キーマップをfixture・配布物へ入れない。
- ヒートマップは論理キー合計の表示。キーボード別集計は初回Publicでは採用せず、接続状態を実打鍵元として表示しない。
- 共通ロジックはWKRCoreと上流の配列JSONへ集約する。Privateの研究計測・推定補正をPublicへ自動取り込みしない。

## 3製品の配布候補

v1 0.7.1-public.1、v2 0.8.0-public.beta.6、練習帳0.2.0を準備中。Web版はwkr-layoutの手動Pages公開で準備する。v1 / v2候補の許可後の短い変換・一時停止・再開・終了後の通常入力は画面共有のキー操作で確認済み。新バイナリのダウンロード後のGatekeeper操作、物理打鍵、更新・アンインストールは確認待ち。Google日本語入力・azooKey・Intel・全OS版は今回の確認済み対象に含めない。

### 入力権限と短い入力確認の結果

練習帳0.2.0のQWERTY体験と、v2同梱練習でのApple日本語入力の確定・採点は画面で確認した。v2候補は両権限が有効になった後、短い入力、一時停止中の通常入力、再開、終了、同梱練習での入力・採点まで確認した。v1候補も両権限の許可後に短い入力・一時停止・再開・終了後の通常入力を確認した。権限設定直後の別セッションで監視タイムアウトによる安全終了を1回確認し、再起動後の短い確認では再発しなかった。原因と長時間利用時の再現性は未特定。詳細と未確認範囲は[検証記録](verification.md)を参照する。
