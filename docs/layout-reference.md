# 配列リファレンス

wkr-macos が実際に送るローマ字と、prefix モードでの1キー目の表示をまとめます。
配列そのものの仕様は上流 [yuhkis/wkr-layout](https://github.com/yuhkis/wkr-layout) が正本です。
このページは **macOS 実装が上流とどう違うか** を明示することが目的です。

**かなは1件を除いて上流と同一です。** 異なるのは Apple日本語入力へ送るローマ字の綴りで、
唯一の例外が `WJ`（上流 `ヴ` → wkr-macos `ゔ`）です。理由と、配列全体の網羅状況は
[layout-coverage.md](./layout-coverage.md) にあります。

---

## 上流との差分の要約

| 項目 | 上流の表 | wkr-macos | 理由 |
| --- | --- | --- | --- |
| `ち` `つ` `ちゃ` など | `chi` / `tsu` / `cha` | `ti` / `tu` / `tya` | 行内で1文字目を揃えるため |
| `ふ` | `fu` | `hu` | 同上（は行の1文字目を `h` に統一） |
| `じ` `じゃ` など | `ji` / `ja` | `zi` / `zya` | 同上（ざ行を `z` に統一） |
| 小書き | `xa` / `xya` 系 | `la` / `lya` 系 | Kotoeri が `x` の連続入力で先頭を切り離すため（後述） |
| `「` `」` `『` `』` | 配列規則 | **素通し** | Apple日本語入力に任せて Space 変換を残すため |
| `■[` `■]` `■{` `■}` | `［］《》` | 実装済み | Google 表のみに存在。JIS の括弧キーと1対1で対応する |
| `■y` | `〒` | 実装済み | `■x` が上流で `〒` と `×` に重複。azooKey に合わせて `×` を `X` に置き、`〒` はこの行から採った |
| `■'` `■"` | `'` `"` | **未実装** | ANSI の Shift+7 / Shift+2。JIS では `■&` → `￡`、`■@` → `▼` と同じ物理キーで両立できない |
| `■i` `■o` | `【` `】` | 追加 | **上流 v1.1 で追加予定の変更を先行実装。** 既存の `Shift+8` / `Shift+9` も引き続き有効 |
| `ヶ` `ゐ` `ゑ` `ゎ` `←↓↑→` | Unicode 直接注入 | `lke` / `wyi` / `wye` / `lwa` / `zh` `zj` `zk` `zl` | ことえりのローマ字表にある綴りを 2026-08-16 に実測。未確定文字列に載る |
| `WJ` のかな | `ヴ` | **`ゔ`**（`vu`） | ひらがなモードでカタカナ `ヴ` を出す綴りがことえりに無い。`ゔ` なら未確定に残り、`ゔぁ` 等も作れて Space で `ヴ` へ変換できる。**唯一のかな差分** |
| `QY → ヵ` | なし | 追加（`lka`） | `ヶ` は `EY` にあったが `ヵ` に対応キーが無く、小書きでも作れなかった。が行の `Y` スロットが空いていた |
| 後置小書き8件 | `HT` `KT` `JT` `;T` `LT` `UT` `IT` `OT` | **全廃** | 母音キーの後の `T` を必ず吸い、`K` `T` `;` が `いぇ` ではなく `ぃえ` になるように、基本かな＋前置小書きの組み合わせを潰していた。小書きは前置形（`TH` `TK` …）だけで入力する |

## なぜ訓令式なのか

prefix モードは「そのキーから到達し得る全出力が共有するローマ字の1文字目」を最初に流します。
行内で1文字目が割れていると共有接頭辞が空になり、1キー目に何も表示できません。

例えばた行が `ta` / `chi` / `tsu` / `te` / `to` のままだと、`t` と `c` が混在して共有接頭辞が空になります。
`ti` / `tu` に揃えれば全出力が `t` で始まり、`F` を押した瞬間に `t` が出せます。
Apple日本語入力は訓令式を受理するので、**かなを変えずに綴りだけ**揃えられます。

### 小書きを `l` 系にした理由（実測）

小書きは当初 `x` 系（`xa` / `xya`）でしたが、2026-08-12 の対照実験で問題が見つかりました。
wkr-macos を止めて Apple日本語入力に素で打った結果です。

| 入力 | 結果 |
| --- | --- |
| `xya` を普通の速さで | `ゃ` ✓ |
| `x` の後に1〜2秒おいて `ya` | `ゃ` ✓ |
| `xyaxyuxyo` を連続で | `xやx湯ょ` ✗ |
| `lyalyulyo` を連続で | `ゃゅょ` ✓ |

Kotoeri 側のローマ字解釈が原因で、連続入力すると先頭の `x` が確定文字として切り離されます
（wkr-macos の合成イベントや reset が原因ではありません。該当時刻に reset ログはありません）。
`l` 系なら連続でも正しく変換されるため、小書きと `て`/`で` 系の小書き部分を
`l` 系に統一しました。

| 入力 | 表示 |
| --- | --- |

## 取り消し（Backspace）が起きる66件

prefix モードで取り消しが起きるのは次の66件だけで、テストで集合として固定しています。
想定外の規則が取り消しを始めるとテストが落ちます。削除は常にBackspace 1回です。

| 分類 | 件数 | 例 | 備考 |
| --- | --- | --- | --- |
| `X` 行の `て`/`で` 系 | 4 | `XU → てぃ`、`XY → てゅ`、`XI → でゅ`、`XO → でぃ` | 行内で `ふ`/`て`/`で` が混在するため、`ふぁ` 系の `f` だけを流す |
| 行の1文字目を継がない出力 | 7 | `WJ → ゔ`（`vu`）、`EY → ヶ`（`lke`）、`QY → ヵ`（`lka`）、`T, → ，`（Unicode） | 行が流した1文字を消してから送る |
| `Y` 記号レイヤー | 55 | `YA → ※`、`YC → 〇` | 仮表示の `z` を消してから記号を注入する |

**ちらつきは残っていません。** 唯一ちらついていた後置小書きは上流 v1.1 で全廃したので、
取り消しはいずれも未合成のローマ字1文字を消すだけです。

削除数は**表示されている単位**で数えます。`k` のような未合成のローマ字は1文字が1単位、
`や` のように送出2文字がすでに1かなに合成されている場合も1単位です。

## 境界キーの扱い

- **Space / Return / Shift+Return / Tab / 句読点 / Shift付き句読点（`？` など） / Shift+英字**
  … 保留中の残りを先に送ってから原キーを通します。押鍵数は変わりません。
  Shift+英字は Apple日本語入力の「英字」モードへの切替なので、`G` の後の `Shift+O` は `はO` になります。
- **出力を持たない状態（`T` や `Y` 単独）で境界キー** … 仮表示の文字は消しません。
  画面に出したものを wkr-macos が勝手に消さない、という方針で統一しています。
- **Escape** … 内部状態だけを破棄し、原キーをそのまま通します。**合成イベントは一切送りません。**
  未確定文字列は Apple日本語入力の所有物なので、その後どうなるかは IME 側の仕様と前面アプリに従います。
  実測では、**TextEdit は Escape 1回ごとに「直前の文節をひらがなへ」「未確定全体をひらがなへ」
  「未確定を破棄」と段階的に戻り、Claude.app では削除されずそのまま確定しました**
  （2026-08-14、範囲は [verification.md](./verification.md) にあります）。
  素のローマ字入力と同じ見え方になります。
- **Backspace** … 送出済みローマ字ちょうどを消して保留を取り消します。既存本文は削除しません。

## `Y` の矢印4件（記号レイヤーではありません）

| 押すキー | JIS刻印 | 出力 | 送るローマ字 |
| --- | :---: | :---: | :---: |
| `Y` → `H` | h | ← | `zh` |
| `Y` → `J` | j | ↓ | `zj` |
| `Y` → `K` | k | ↑ | `zk` |
| `Y` → `L` | l | → | `zl` |

この4件だけはことえりのローマ字表に同じ綴りがあるので、Unicode ではなくローマ字で送ります。
未確定文字列に載るため、**文中でも動き、Space 変換も `英数` 2回押しの読み戻しも効きます。**
`--symbol-layer off` でも外れません。`Y` の仮表示 `z` はこの4件の共有接頭辞です。

## `Y` 記号レイヤー全55件

> **この55件は Unicode 直接注入です。** その場で確定するため Space で変換し直せず、
> 未確定文字列があるときは送られません（2026-08-16 実測）。丸ごと無効にする
> `--symbol-layer off` があります。使い方は [install.md](./install.md#y-レイヤーを無効にする)、
> 根拠は [design.md](./design.md) 5.4 にあります。

`Y` を押してから2打鍵目を押します。prefix モードでは1打鍵目で仮表示の `z` が出て、
記号が決まった時点で Backspace 1回で消えます。「JIS刻印」はそのキーに印字されている文字です。
