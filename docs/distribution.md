# ダウンロードしたアプリを使う

3種類のアプリを用意します。いずれもApple Silicon・macOS 14以降が対象で、利用者側のXcodeは不要です。ad-hoc署名・未公証です。Appleの開発元証明・公証済みのアプリではありません。

| 製品 | アプリ版 | 対応配列 | アプリ / Bundle ID |
| --- | --- | --- | --- |
| WKR macOS v1 | 0.7.1-public.1 | 1.1.0 | WKRV1.app / io.github.yuhkis.wkr-macos.v1 |
| WKR macOS Public v2 | 0.8.0-public.beta.6 | 2.0.0-beta.1 | WKRPublic.app / io.github.yuhkis.wkr-macos.public |
| わから v2 練習帳 | 0.2.0 | 2.0.0-beta.1 | WakaraPractice.app / io.github.yuhkis.wkr-practice |

練習帳の教材はv2だけです。v1アプリにv2教材は同梱しません。v2アプリにも同じ練習帳0.2.0を同梱します。アプリ版と配列版はメニュー・練習画面・実行ファイルの `--version` で確認できます。

## 入手と初回起動

1. [公式Release](https://github.com/yuhkis/wkr-macos/releases)で製品・版を選び、ZIPとSHA256SUMSを取得します。ファイル名にarm64-adhocが含まれるものが今回の配布形式です。
2. ターミナルで `shasum -a 256 ダウンロードしたファイル.zip` を実行し、SHA256SUMSと一致することを確認します。ハッシュは破損・取り違えの検査であり、開発元の証明ではありません。
3. ZIPを展開し、選んだアプリをFinderで「アプリケーション」へコピーします。旧版があれば先に終了し、必要なら控えを残してから置き換えます。
4. アプリを一度開きます。macOSが未確認の開発元としてブロックした場合は、入手元とハッシュを確認し、システム設定 → プライバシーとセキュリティ →「このまま開く」で、そのアプリだけを許可します。[Appleの手順](https://support.apple.com/ja-jp/102445)を参照してください。

Gatekeeper全体の無効化やquarantine属性の一括削除は行いません。再ビルド・更新後に個別の許可を求められる場合があります。ad-hoc署名はAppleアカウントや証明書の登録を使わず作成します。配布アプリに個人の証明書は添付しません。

## WKR v1 / v2で入力する

1. 他のWKR変換アプリを終了します。v1とv2・Privateは同時に変換させません。ログイン時に古い版が起動する設定も確認します。
2. アプリの案内からシステム設定の「入力監視」「アクセシビリティ」を開き、起動したWKRV1.appまたはWKRPublic.appを許可します。独立した練習帳には、この二つの許可は不要です。
3. 案内の「状態を再確認して変換を開始」を選びます。Apple日本語入力をローマ字入力・ひらがなに自分で切り替えます。
4. 破棄できるTextEditの新規書類で `E K` →「き」を確認し、Space・Enter・Backspaceを試します。メニューの「変換を一時停止」で通常入力に戻し、「変換を再開」で戻します。
5. 終了はアプリのメニューから行います。入力ソースを自動変更しないため、終了後も選択中の日本語入力をそのまま使えます。

初回の対象はApple日本語入力とJISキー位置です。Google日本語入力・azooKeyでは、アプリの対応を確認したとは扱いません。[配列リポジトリ](https://github.com/yuhkis/wkr-layout)の専用テーブルによる経路を案内しています。詳細な設定・安全停止条件は[install.md](https://github.com/yuhkis/wkr-macos/blob/main/docs/install.md)、実測の範囲は[verification.md](https://github.com/yuhkis/wkr-macos/blob/main/docs/verification.md)です。

## 練習する

- **QWERTYで体験**: ABC・英数に切り替え、練習欄に表示されたキーを入力します。ページ内でかなに変換し、Enterで採点します。標準設定のWKRはABCでは変換しないので、起動したままで使えます。
- **WKR・IMEで練習**: WKR v2と普段の日本語入力でひらがなを確定し、もう一度Enterで採点します。練習帳側では再変換しません。

WakaraPractice.appは変換エンジンを起動せず、WKRと同時に使えます。v2アプリではメニューから同じ教材を開けます。両アプリとも教材・変換規則を同梱し、オフラインで使えます。ブラウザ版も同じ教材です。Web版は初回読み込み時に通信し、GitHubがアクセス時のIPアドレスを記録します。アプリや練習ページが入力内容を送信する処理はありません。

保存は既定オフです。有効にした場合だけ、配列版・課題ID・完了回数・最高正答率を保存します。入力本文・誤入力・キー列・日時・所要時間は保存しません。画面の「保存した成績をすべて削除」で削除できます。保存をオフにした場合も現在の成績を削除します。

## 設定と保存先

macOSの設定ドメインとApplication Supportのフォルダ名は上表のBundle IDです。相互の自動移行・同期は行いません。

| 保存物 | 場所・削除方法 |
| --- | --- |
| v1 / v2の任意の日別キー頻度 | `~/Library/Application Support/<Bundle ID>/key-frequency.json`。既定オフ。終了後に対象アプリの `--key-frequency-reset` で現在の集計を削除。archiveは別途本人が確認して削除 |
| macOS練習帳0.2.0の成績 | v2または練習専用の同フォルダ内 `practice-progress-v2.json`。画面から削除 |
| 練習帳0.1.0の成績 | 旧 `practice-progress.json` は保持して自動移行しない。旧版の画面、または終了後にそのファイルだけを本人が削除 |
| ブラウザ練習帳0.2.0の成績 | そのサイトのlocalStorage `wakara.practice.v2.2.0.0-beta.1`。画面またはブラウザのサイトデータ管理で削除 |

頻度は暦日・規則表ID・論理キーとShiftごとの回数だけです。図で選ぶキーボードは表示用で、実際の打鍵元を識別しません。公開ZIPへ利用者の設定や保存データを入れません。

## 更新・切り戻し・アンインストール

終了してからアプリを置き換え、版表示と権限を確認します。v1保存ソース版・Privateから設定を丸ごと移さず、新しいアプリで必要な項目だけ選びます。成績0.2.0は採点方式が異なるため旧版と保存先を分けています。

アンインストールは、本人が登録したログイン項目を解除し、アプリを終了してからアプリ本体をゴミ箱へ移します。変換アプリの入力監視・アクセシビリティの登録を削除します。成績は事前に画面から削除でき、設定・頻度も不要なら上表の**対象製品だけ**のApplication Supportと設定ドメインを確認して削除します。旧版やPrivateのデータは別です。配布アプリはログイン項目を自動登録しません。

今回のバイナリでのダウンロード後の起動許可、TCC権限、物理打鍵、停止後の通常入力、更新・アンインストールは実機確認と区別して記録します。ローカルビルド成功をこれらの実機確認には数えません。
